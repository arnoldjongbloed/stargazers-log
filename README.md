# stargazers-log
A log of the repositories I've starred.

Serve this directory over HTTP (for example, run `python -m http.server`),
then visit http://localhost:8000. Opening the HTML file directly may prevent
the browser from fetching the sample data.

Based on GitHub's [Writing and storing your code](https://docs.github.com/en/get-started/start-your-journey/writing-and-storing-your-code) guide.
